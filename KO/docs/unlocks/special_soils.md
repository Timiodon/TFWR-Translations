# 진주암과 양토
이 해금 항목은 지하에 진주암과 양토(`Grounds.Perlite`와 `Grounds.Loam`)라는 두 가지 새 블록을 추가합니다. 이 토양에 심은 작물을 수확하면 수확량이 두 배가 됩니다.

진주암과 양토는 점토처럼 얇은 지하층으로 생성되지만 좀 더 드뭅니다.

진주암은 공기가 잘 통하는 토양을 좋아하는 선인장, 대나무, 덤불, 나무에 잘 맞습니다. 이 식물들을 진주암에 심으면 수확량이 두 배가 되죠.

양토는 당근과 해바라기에 잘 맞습니다. 양토에 심으면 수확량이 두 배가 됩니다.

진주암과 양토는 바로 심을 수 있다는 장점도 있습니다. `Grounds.Grassland`처럼 먼저 `till()`로 `Grounds.Soil`로 바꿀 필요가 없죠.
