# Explosive Drill
Put on the explosive drill using `change_hat(Hats.Explosive_Drill)`.

Calling `dig()` while the explosive drill is equipped consumes one `Items.Dynamite` and triggers an explosion similar to `use_item(Items.Dynamite)`. Unlike a regular dynamite explosion, however, it collects every block caught in the blast!

You only have one explosive drill, so only one drone can equip it at a time.
