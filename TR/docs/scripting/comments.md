# Yorumlar
Yorumlar, kodun yürütme sırasında yok sayılan kısımlarıdır.
Yorum eklemek için `#` kullanılır. Aynı satırda `#` işaretinden sonra gelen her şey yorumdur ve yok sayılır.

{{codeexample 
{
    "show_image": false,
    "show_code": true,
    "show_inventory": false,
    "show_output": true,
    "collapsing": true,
    "autoplay": false,
    "execution_speed": 1,
    "digging_speed": 1,
    "action_ticks": 200,
    "operation_ticks": 100,
    "seed": 0,
    "exclude_unlocks": ["watering", "fertilizer"],
    "starting_chunk": 0,
    "dlc_enabled": false
}
#SETUP
#CODE
#this is a comment
#harvest()
}}

Bu, koda not eklemek ya da kodun bazı kısımlarını silmeden geçici olarak devre dışı bırakmak için işe yarar.

Bir fonksiyon tanımından hemen önceki satırdaki yorum, fareyle fonksiyon adının üzerine geldiğinde çıkan bilgi penceresinde gösterilir.
