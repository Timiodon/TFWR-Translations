# Tuple'lar
Tuple'lar (demetler), birden fazla değeri tek bir değerde birleştirmenin harika bir yoludur.
Bir tuple oluşturmak için değerleri virgülle ayırman yeterli:

{{codeexample 
{
    "show_image": false,
    "show_code": true,
    "show_inventory": false,
    "show_output": true,
    "collapsing": true,
    "autoplay": false,
    "execution_speed": 1,
    "digging_speed": 1,
    "action_ticks": 200,
    "operation_ticks": 100,
    "seed": 0,
    "exclude_unlocks": ["watering", "fertilizer"],
    "starting_chunk": 0,
    "dlc_enabled": false
}
#SETUP
#CODE
tuple = 1, 2
print(tuple)
}}

Onları birden fazla değişkene de açabilirsin. Aşağıdaki kodda `(1, 2)` tuple'ı `a` ve `b` adlı iki değişkene açılır.

{{codeexample 
{
    "show_image": false,
    "show_code": true,
    "show_inventory": false,
    "show_output": true,
    "collapsing": true,
    "autoplay": false,
    "execution_speed": 1,
    "digging_speed": 1,
    "action_ticks": 200,
    "operation_ticks": 100,
    "seed": 0,
    "exclude_unlocks": ["watering", "fertilizer"],
    "starting_chunk": 0,
    "dlc_enabled": false
}
#SETUP
#CODE
a, b = 1, 2
print(a)
a, b = b, a
print(a)
}}

Tuple'lar listeler gibi indekslenebilir, ancak değiştirilemezler; oluşturulduktan sonra üzerlerinde değişiklik yapılamaz.

{{codeexample 
{
    "show_image": false,
    "show_code": true,
    "show_inventory": false,
    "show_output": true,
    "collapsing": true,
    "autoplay": false,
    "execution_speed": 1,
    "digging_speed": 1,
    "action_ticks": 200,
    "operation_ticks": 100,
    "seed": 0,
    "exclude_unlocks": ["watering", "fertilizer"],
    "starting_chunk": 0,
    "dlc_enabled": false
}
#SETUP
#CODE
tuple = 1, 2
print(tuple[1])

tuple[0] = 3
}}
