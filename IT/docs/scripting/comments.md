# Commenti
I commenti sono parti del codice che vengono ignorate durante l'esecuzione.
I commenti possono essere aggiunti usando `#`. Qualsiasi cosa sulla stessa riga dopo `#` è un commento e sarà ignorata.

{{codeexample 
{
    "show_image": false,
    "show_code": true,
    "show_inventory": false,
    "show_output": true,
    "collapsing": true,
    "autoplay": false,
    "execution_speed": 1,
    "digging_speed": 1,
    "action_ticks": 200,
    "operation_ticks": 100,
    "seed": 0,
    "exclude_unlocks": ["watering", "fertilizer"],
    "starting_chunk": 0,
    "dlc_enabled": false
}
#SETUP
#CODE
#questo è un commento
#harvest()
}}

Questo può essere utile per aggiungere note al codice o disabilitarne temporaneamente alcune parti senza eliminarle.

Un commento sulla riga che precede la definizione di una funzione diventa parte delle informazioni visualizzate quando passi il mouse sul nome della funzione.
