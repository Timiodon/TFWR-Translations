# 爆発ドリル
`change_hat(Hats.Explosive_Drill)`で爆発ドリルを装備してください。

爆発ドリルを装備して`dig()`を呼ぶと、`Items.Dynamite`を1個消費し、`use_item(Items.Dynamite)`と同様の爆発を起こします。ただし、通常のダイナマイトの爆発とは違い、爆風に巻き込まれたすべてのブロックを回収します！

爆発ドリルは1つしかないため、同時に装備できるドローンは1台だけです。
