# パーライトと壌土
このアンロックでは、地下にパーライトと壌土（`Grounds.Perlite`と`Grounds.Loam`）という2つの新しいブロックの種類が追加されます。これらの土壌に植えた植物を収穫すると、収穫量が2倍になります。

パーライトと壌土は粘土と同じように地下の薄い層として現れますが、少し珍しい土壌です。

パーライトは通気性のよい土壌を好むサボテン、竹、茂み、木に適しています。これらの植物をパーライトに植えると、収穫量が2倍になります。

壌土はニンジンとヒマワリに適しています。これらをここに植えると収穫量が2倍になります。

パーライトと壌土はそのまま植えられるのも利点です。`Grounds.Grassland`のように`till()`で`Grounds.Soil`に変える必要はありません。
