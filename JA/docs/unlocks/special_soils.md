# パーライトと壌土

通気性がよい土壌や養分の豊富な土壌では、収穫量が増える植物があります。このアンロックでは、地下にパーライトと壌土（`Grounds.Perlite`と`Grounds.Loam`）という2つの新しいブロックの種類が追加されます。

これらの新しいブロックの種類は粘土と同じように、地下に薄い層として現れます。

パーライトは通気性のよい土壌を好むサボテン、竹、茂み、木に適しています。これらの植物をパーライトに植えると、収穫量が2倍になります。

壌土はニンジンとヒマワリに適しています。これらをここに植えると収穫量が2倍になります。

パーライトと壌土は、それらに適した植物を植える前に`till()`を呼ぶ必要がないというもう一つの利点もあります。
