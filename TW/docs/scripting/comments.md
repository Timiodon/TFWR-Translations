# 註解

被註解的內容，在程式執行期間不會被執行。

可以使用 `#` 來新增註解。`#` 之後的所有內容都是註解，不會被程式執行。

{{codeexample 
{
    "show_image": false,
    "show_code": true,
    "show_inventory": false,
    "show_output": true,
    "collapsing": true,
    "autoplay": false,
    "execution_speed": 1,
    "digging_speed": 1,
    "action_ticks": 200,
    "operation_ticks": 100,
    "seed": 0,
    "exclude_unlocks": ["watering", "fertilizer"],
    "starting_chunk": 0,
    "dlc_enabled": false
}
#SETUP
#CODE
#這是一條註解
#harvest()
}}

註解可以在程式碼中新增筆記，或者在不刪除程式碼的情況下暫時停用部分程式碼，用來偵錯你編寫的程式。

在函式定義前一行新增註解，該註解會出現在滑鼠懸停於函式名稱時顯示的資訊中。
