# 匯入
如果把所有的程式碼都放在一個檔案裡，很快就會變得難以管理。
使用 `import` 陳述式可從另一個檔案匯入函式和全域變數。
一張截圖說明它的工作原理：
![|x400](ImportsInOnePicture)

這裡 `import module2` 會執行名為 `module2` 的檔案，讓你能存取其中所有的全域變數。
然後你可以使用 `.` 運算子來存取匯入模組中的變數和函式。
所以在這個例子中，`module2.print_x()` 呼叫了 `module2` 中的 `print_x()`。

### 無需繼續閱讀

你也可以使用 `from` 語法，將匯入模組中的全域變數移到執行匯入陳述式的目前作用域中。

`from module2 import print_x
print_x()`
只從 `module2` 匯入指定的全域變數。

或者

`from module2 import *
print_x()`
從 `module2` 匯入所有全域變數。

這同樣會匯入 `module2` 檔案，但不是透過一個名為 `module2` 的變數來存取它，而是將 `module2` 中的全域變數解包並直接賦給區域作用域。

通常不推薦這種匯入形式，因為它在兩個檔案相互匯入時效果不佳，而且你可能會因為命名衝突而意外覆蓋匯入檔案中的變數。如果不清楚自己在做什麼，最好避免使用 `from` 語法。

# 真實工作原理

## 重點摘要
匯入機制可能不太直觀，但只要堅持使用 `import file` 而非 `from file import`，並將所有不是全域定義的內容包裹在如下程式碼區塊中：
`if __name__ == "__main__":`
就可以避免大多數問題。

## 匯入的副作用
第一次匯入一個檔案時，會完整執行一遍這個檔案，然後讓你能存取在執行過程中定義的所有變數。
如果再次匯入同一個檔案，則只會再次回傳第一次的快取模組。

這意味著 import 陳述式可能會產生副作用：如果匯入的檔案呼叫了 `harvest()`，該檔案會在匯入過程中實際執行收穫。但再次匯入時，因為檔案只執行一次，所以不會再次收穫。

若要避免這種副作用，可以使用 `__name__` 變數。這個變數在檔案被直接執行時，會被自動設定為 `"__main__"`；在檔案透過 `import` 執行時，則會被設定為該檔案的名字。
一種好的做法是，將任何你不想在檔案被匯入時執行的程式碼，都放在 `if __name__ == "__main__":` 程式碼區塊中。

在 Python 中，一個常見的檔案結構就是，把檔案執行時應執行的程式碼放入 `main()` 函式中。這樣，你就能清楚地區分區域變數（在 `main()` 內部定義）和可以被匯入的全域變數（在 `main()` 外部定義）。

`a_global_variable = "global"

def main():
    a_local_variable = "local"
    # 執行某些操作

if __name__ == "__main__":
    main()`

## 匯入迴圈
如果檔案 `a` 匯入檔案 `b`，同時檔案 `b` 又匯入檔案 `a`，會發生什麼？

檔案 `a`：
`import b
x = 0`

檔案 `b`：
`import a
def f():
    print(a.x)`

這樣寫是沒問題的。假設這兩個檔案都還沒有被載入，然後其他人執行了 `import a`。

- `a` 執行到 `import b` 這一行。
- `b` 執行到 `import a` 這一行。
- 快取模組 `a` 已經存在，但不包含 `x`，因為它只執行到了 `import b` 這一行。
- `b` 將對載入了一半的模組 `a` 的引用儲存在一個名為 `a` 的變數中。
- `b` 執行 `def` 陳述式並儲存函式 `f()`。
- `a` 繼續執行並初始化 `x`。

當有人呼叫 `b.f()` 時，`0` 會被正確列印出來，因為 `b` 所引用的模組 `a` 現已完全載入。

現在來看看使用 `from` 語法的相同程式碼。

檔案 `a`：
`from b import *
x = 0`

檔案 `b`：
`from a import *
def f():
    print(x)`

- `a` 執行到 `from b import *` 這一行。
- `b` 執行到 `from a import *` 這一行。
- 模組 `a` 已經存在，但還沒有被完全執行。
- `b` 將 `a` 中目前存在的所有內容解包到它自己的全域作用域中。此時，`a` 什麼也不包含，因為它還沒有執行到 `x = 0` 這一行，所以什麼也沒有被匯入。
- `b` 執行 `def` 陳述式並儲存函式 `f()`。
- `a` 繼續執行並初始化 `x`。

如果現在有人呼叫 `b.f()`，則會收到錯誤，提示 `x` 在目前作用域中不存在。這是因為這一次 `b` 沒有一個指向仍在載入中的 `a` 的引用，也看不到在匯入之後才新增的定義。
