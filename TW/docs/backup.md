# 載入備份
有時存檔檔案可能會損壞，或者一些程式碼檔案會遺失。如果發生這種情況，試試載入備份。如果頻繁發生，再試試關閉 Steam 雲同步。

每次儲存遊戲時都會建立一個備份，並保留少量備份以備不時之需。
這些備份可以在[備份目錄](persistent_data_path/Backup)中找到。它們是[存檔目錄](persistent_data_path/Saves)中存檔的副本。
載入備份最簡單的方法便是，將你想要載入的特定備份資料夾複製到存檔目錄。

存檔是包含 1 個 `save.json` 檔案和 1 堆 `.py` 檔案的資料夾。
如果只遺失了幾個程式碼檔案，或者程式碼檔案還在但 `save.json` 檔案損壞，也可以只用備份中對應的檔案替換損壞的檔案。
