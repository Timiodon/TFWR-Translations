# 爆破鑽頭
使用 `change_hat(Hats.Explosive_Drill)` 裝備爆破鑽頭。

裝備爆破鑽頭時呼叫 `dig()`，會消耗 1 份 `Items.Dynamite`，並引發類似 `use_item(Items.Dynamite)` 的爆炸。不過，與一般的炸藥爆炸不同，它會收集爆炸波及的每個地塊！

你只有一個爆破鑽頭，因此同一時間只能由一架無人機裝備。
