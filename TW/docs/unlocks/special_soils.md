# 珍珠岩與壤土

有些植株在疏鬆或養分豐富的土壤中產量更高。此解鎖項新增兩種地下地塊：珍珠岩和壤土（`Grounds.Perlite` 和 `Grounds.Loam`）。

這兩種地塊與黏土類似，會在地下形成薄層。

珍珠岩適合喜歡疏鬆土壤的植物：仙人掌、竹子、灌木和樹木。種植在珍珠岩上時，這些植株的產量翻倍。

壤土適合胡蘿蔔和向日葵。種植在壤土上時，這些植株的產量翻倍。

珍珠岩和壤土還有一個好處：種植適合這些土壤的作物前，無需呼叫 `till()`。
