# 模擬

模擬可以讓你快速測試程式碼，而不會改變真實農場的狀態。
模擬的起始狀態可以自由選擇，當模擬結束時，真實農場將恢復到模擬開始前的確切狀態。

呼叫 `simulate()` 函式來開始一次模擬。

指定執行的起始檔案
`filename = "f1"`

以所有科技樹項目全部解鎖並全部滿級的狀態開始
`sim_unlocks = Unlocks`

以 10000 根胡蘿蔔和 50 捆乾草開始
`sim_items = {Items.Carrot : 10000, Items.Hay : 50}`

以一個值為 13 的全域變數 "a" 開始
`sim_globals = {"a" : 13}`

使用固定的隨機種子
`seed = 0`

將模擬速度提高到 64 倍
`speedup = 64`

執行模擬程式
`run_time = simulate(filename, sim_unlocks, sim_items, sim_globals, seed, speedup)`

呼叫 `simulate()` 函式會回傳模擬給定起始檔案所花費的時間（以秒為單位）。

### 檔案名稱
`simulate()` 函式的第一個參數是檔案名稱，即顯示在程式碼視窗頂部的名稱。模擬將執行指定的檔案，就像你按一下了它的執行按鈕一樣。

### 起始科技樹項目
所有的程式設計功能，如迴圈、`if` 陳述式、串列、字典……將始終保持解鎖狀態。

第二個參數可用來指定模擬開始時，除了程式設計功能外，還需要知道科技樹項目解鎖/升級哪些內容。該參數必須是一個科技樹項目序列。模擬將以序列中所有科技樹項目都升級到最高等級的狀態開始。

如果想指定非最高級的升級等級，可以傳遞一個將科技樹項目對應到解鎖等級的字典。在這種情況下，負值對應於最高解鎖等級。

### 起始物品
第三個參數可用來傳遞一個將物品對應到數量的字典，從而指定模擬開始時擁有的物品數量。

### 起始全域變數
由於模擬開始的是一次全新的程式執行，所以無法存取啟動模擬的程式中的變數。
但是，第四個參數可以用來將值傳遞給模擬。這是一個將字串形式的變數名稱對應到值的字典。這些變數隨後會被新增到模擬內部執行的全域作用域中。

請注意，這會複製所有值，所以在模擬內部修改它們不會影響模擬外部的原始值。除了執行所需的時間外，無法從模擬中回傳其他值。

### 隨機種子
第五個參數可以用來指定模擬中使用的隨機種子。這必須是一個正整數。負值將導致使用隨機種子。

隨機種子會影響方方面面的參數，從植物生長時間到迷宮版面配置再到水分蒸發時間等等。如果使用相同的隨機種子和相同的起始條件多次開始同一個模擬，結果應該始終是一樣的。

### 加速
第六個參數是模擬的起始速度倍率，以便快速完成測試。如果遊戲跟不上設定的速度，則會自動減速。

加速不會以任何方式影響模擬的結果。它的存在只是為了減少等待時間。
