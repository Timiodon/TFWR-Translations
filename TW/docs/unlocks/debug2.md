# 偵錯 2
當無人機速度太快，或者網格太大時，可能很難判斷具體情況。

函式 `set_execution_speed()` 和 `set_world_size()` 便應運而生。
它們可用來減慢執行速度和縮小農場。

農場大小和執行速度將在執行結束時重設為預設值。
