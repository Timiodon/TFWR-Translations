# Добыча
Теперь дрон оснащен примитивным буром, позволяющим искать клады под землей.

Команда `dig()` позволяет раскопать блок под дроном.

Наведи курсор на блок, чтобы увидеть его название, устойчивость и твердость.

# Бур
Чем глубже ты копаешь, тем тверже становятся блоки, из-за чего на раскопки уходит больше времени. К счастью, бур можно улучшать!

Чтобы дрон ориентировался под землей, поскорее открой [Подземные датчики](docs/unlocks/underground_senses.md). Они позволят проверять координату z, тип земли, ее твердость и устойчивость.

Например, с [Подземными датчиками](docs/unlocks/underground_senses.md) можно использовать `get_hardness()` для проверки твердости блока под дроном. Встретив особенно твердые блоки, иногда лучше обойти их, чтобы продвигаться быстрее:

`while True:
    if get_hardness() < 5:
        dig()
    else:
        move(East)`

Конечно, с глубиной блоки становятся все тверже, поэтому эта стратегия помогает лишь до определенного момента.

## Обвалы
При копании вниз окружающие блоки обваливаются. Четыре соседних с дроном блока уничтожаются всегда. Затем обвал распространяется в зависимости от устойчивости земли. Блок с устойчивостью 1, например луг, выдерживает перепад высоты в 1 блок. Иными словами, если по вертикали или горизонтали с лугом соседствует блок, координата Z которого ниже на 2 или более, луг будет уничтожен.

Устойчивость блока указана во всплывающей подсказке.

При обвале блока уничтожаются и все блоки над ним. Ресурсы даются только за блоки, которые дрон прокопал напрямую, поэтому уничтоженные обвалом блоки ничего не приносят.
