# Уголь
Под землей скрыты разные руды, которые ждут, пока ты их найдешь и выкопаешь. Пройдя поверхность и начав копать `Grounds.Dirt`, первым ты найдешь уголь.

Для добычи угля не нужно ничего особенного: выполни `dig()`, когда дрон находится прямо над блоком `Grounds.Coal`. Используй `get_ground_type()` для проверки земли под дроном и `get_ground_type(direction)` для четырех соседних блоков.

## Примечание об обвалах
Уголь дается только за напрямую выкопанные угольные блоки, а не за обвалившиеся вокруг дрона. Учитывай это, чтобы выкопать как можно больше угля и как можно меньше потерять при обвалах.

## Строение жил
Жилы образуют горизонтальные пласты толщиной 1 блок, на которые нужно наткнуться при раскопке земли. Большинство угольных блоков в пласте соседствуют напрямую, но некоторые соединяются только по диагонали.

Угольные залежи растут пропорционально ферме, поэтому дальше улучшай [Расширение](unlocks/expand), чтобы добывать больше угля.

## Стратегия
<spoiler=показать подсказку> 
Простая стратегия, особенно на маленьких фермах, — выкопать все блоки на глубине найденного угля. Для эффективности отмечай замеченный уголь через `get_ground_type(direction)` и не трать время на перемещение над землей. Не пропускай диагональные соединения: двигаясь только по углю, ты их не заметишь.
</spoiler>
