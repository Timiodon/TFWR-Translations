# 珍珠岩与壤土
此解锁项新增两种地下地块：珍珠岩和壤土（`Grounds.Perlite` 和 `Grounds.Loam`）。收获种在这些土壤上的作物时，产量会翻倍。

珍珠岩和壤土与黏土类似，会在地下形成薄层，但更稀有一些。

珍珠岩适合喜欢疏松土壤的植物：仙人掌、竹子、灌木和树木。种植在珍珠岩上时，这些植株的产量翻倍。

壤土适合胡萝卜和向日葵。种植在壤土上时，这些植株的产量翻倍。

珍珠岩和壤土还有一个好处：可以直接种植，不像 `Grounds.Grassland`，需要先用 `till()` 变为 `Grounds.Soil`。
